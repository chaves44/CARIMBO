# CARIMBO

Carimbo de Fotos: aplicativo Android de uso pessoal da A R Chaves Engenharia e Projetos.

* Tira a foto pela câmera do celular ou escolhe da galeria
* Carimba data, hora, coordenadas, altitude, bairro, cidade, OS e uma linha livre
* Bairro e cidade pelo OpenStreetMap (sem internet, usa a lista de municípios do IBGE)
* Editor: texto do carimbo, posição, tamanho, girar, cortar, brilho e contraste
* Data, hora e coordenadas da captura não podem ser alteradas
* Salva em Imagens › Carimbo, com o GPS e a data gravados no arquivo

O APK é gerado automaticamente pelo GitHub Actions a cada envio e fica em Releases.
